# Windows 试用指南

## 解压试用包

适用 Windows 10/11 x64。先通过系统托盘退出旧版 Foldergrid，然后把 `Foldergrid-Windows-x64-dev.zip` **完整解压到一个文件夹**，双击其中的 `folder-grid.exe`。请保留 resources、DLL 和其他文件，不能只复制 exe。

该包在 macOS 交叉打包，未签名，未编辑程序资源，exe 图标可能仍是 Electron 默认图标；以你的 Windows 实际运行结果为准。源码版可在 Windows 执行 `npm run dist` 生成标准安装包。

## 建议验收顺序

1. 使用工具条 📂 选择一个测试根目录，创建格子；拖入几份测试文件。验证 v0.3.0 的位置、底色、封面、预览和回收站仍正常。
2. 点击 `⌕`：按文件名和格子名搜索，多词用空格分隔；测试 Enter、方向键、打开和 ↗ 定位。
3. 打开格子：切换最近修改、大小、类型、名称排序和类型筛选；重启确认排序保留；切回自由摆放检查旧位置。
4. 点击 `⊞`：选择一个外部测试文件夹；确认原文件没有移动。验证预览、打开、修改后刷新、断开磁盘提示；右键移除映射，确认原文件保留。
5. 在桌面放几份 `.txt`、`.png` 测试文件。点击 `▤` 生成清单；核对来源与目标，预览阶段文件应未移动。执行后检查，再点击撤销移回。桌面已有其他匹配文件时，可先设置包含专用关键词的规则并关闭默认规则。
6. 在分类规则中验证后缀、关键词、启停和顺序。同名目标、修改后的文件、撤销时原位重名都应跳过，并显示原因。
7. 测试 `Ctrl+Shift+Space`、`Ctrl+Shift+F`、`Ctrl+Shift+H`，等待超过 3 秒确认隐藏状态不会被桌面重连定时器取消；Esc 或切到其他窗口后应退出呼出置顶。
8. 在 Windows 设置中切换 100%/125%/150% 缩放；重启 Explorer；使用真实资源管理器窗口和多标签页验证拖入、移出、回收站。当前仍只在主屏布置格子。

## 源码开发与测试

在 Windows 安装 Node.js 24 LTS，解压源码后打开终端：

```powershell
npm ci
npm run check
npm test
npm run test:smoke
npm run test:desktop
npm start
```

自动化只使用测试目录，不操作个人桌面内容。`test:desktop` 需要已登录的可交互 Windows 桌面。真实 Win32、Explorer 和全局快捷键行为以此机器上的验收为准。

## 反馈位置

启动失败可查看 `%TEMP%/folder-grid-debug.log`。自动化结果位于项目 `.test-output/`。记录 Windows 版本、缩放比例、操作顺序、错误文字即可定位；无需分享包含个人文件内容的配置或日志。
